Bit Art

High Concept

I plan to expand on the pixel artist HW that was offered as an extra credit opportunity. It will allow the user to create pixel art projects and return to them whenever they wish. I plan to add more custumization options to further the experience.

Genre

The genre of this project would align closest to a drawing editor. It functions as a tool.

Platform

This tool will be made for usage on the web, using a PC.

Gameplay

I plan to implment a color palette feature splotches of color that the user can directly click on to use on the canvas. I will also add a portion to the sidebar where the user can add their own colors to the palette by entered a hex code.

I will also implement a saving and loading system in which the user can save their project under a name at any time and return to it later. All saved projects will be listed below the editor window.

In addition to these features, I will add a clear button, which return's all cells on the canvas to white, and an erase button that returns any cell the user clicks on to white.
